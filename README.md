# Igreja Aberta: documentação

Sistema **simples, aberto e modular** para paróquias, que cresce de um núcleo pequeno até uma gestão completa (ERP paroquial). Cada paróquia instala no próprio servidor. Mantido pelo Zenoi nas horas livres; contribuições e doações são bem-vindas.

> Nome de trabalho: "Igreja Aberta". Status desta documentação: **rascunho 0.1 (21/10/2026)**. Itens marcados como "a validar" dependem de fonte, advogado, contador ou autoridade eclesiástica antes de virar regra.
